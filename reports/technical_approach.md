
# Technical Approach Report
## Revio InsightAI

## 1. Project Overview

Revio InsightAI is a Python-based proof of concept for explainable customer review intelligence.

It analyzes customer reviews, predicts sentiment, identifies complaint categories, assigns priority, and generates suggested responses.

The application is built as a Streamlit web application.

## 2. Technology Stack

| Technology | Purpose |
|---|---|
| Python | Core programming language |
| Streamlit | Interactive web application |
| Pandas | Dataset handling |
| Scikit-learn | TF-IDF and Logistic Regression |
| NumPy | Numerical operations |
| Plotly | Interactive dashboard charts |
| SQLite | Review history storage |
| Pytest | Automated testing |

## 3. System Architecture

The processing workflow is:

1. User enters a review or uploads a CSV file.
2. Text preprocessing normalizes the review.
3. TF-IDF converts text into numerical features.
4. Logistic Regression predicts sentiment.
5. Keyword-based classification identifies complaint categories.
6. Rule-based logic determines priority and reasons.
7. A template-based module generates a suggested response.
8. The results are displayed in Streamlit.
9. The analysis is stored in SQLite.

## 4. Module Description

### preprocessing.py
- Converts text to lowercase.
- Removes URLs and special characters.
- Normalizes whitespace.

### sentiment.py
- Uses TF-IDF with unigram and bigram features.
- Uses Logistic Regression for sentiment classification.
- Maps ratings of 4–5 to positive, 1–2 to negative, and 3 to neutral.
- Returns predicted sentiment and model confidence.
- Includes a held-out evaluation method.

### classification.py
- Uses keyword matching to identify complaint categories.
- Supports multiple issue categories in a single review.

### priority.py
- Uses review rating, sentiment, and urgency keywords.
- Assigns High, Medium, or Low priority.
- Returns explanations for the decision.

### response_generator.py
- Generates template-based draft responses.
- Uses sentiment and issue categories.
- Does not automatically send messages.

### database.py
- Uses SQLite to store analyzed reviews.
- Maintains review history.
- Supports retrieving saved analyses.

### app.py
- Provides Dashboard, Analyze Review, Upload Reviews, and Review History pages.
- Displays charts, analysis results, and downloadable CSV reports.

## 5. Model Evaluation

The sentiment model uses a stratified train/test split.

Current demonstration results:

| Metric | Result |
|---|---:|
| Dataset size | 60 reviews |
| Test samples | 15 |
| Test accuracy | 73.3% |

Precision, recall, F1-score, and confusion matrix are also generated by the application.

Important evaluation limitations:
- The dataset is synthetic.
- Labels are derived from star ratings.
- The test set is small.
- The evaluation is not an independent real-world benchmark.

The model confidence represents its predicted class probability, not a guarantee that the prediction is correct.

## 6. Testing

Automated tests are implemented using Pytest.

Test coverage includes:
1. Text preprocessing.
2. Multi-issue classification.
3. High-priority detection.
4. Low-priority detection.
5. Suggested response generation.
6. Sentiment prediction.
7. Database saving and retrieval.

**Test result: 7 passed in 2.78 seconds.**

## 8. Limitations

The current implementation is a demonstration prototype.

- It does not connect to live Revio data.
- It does not use a production LLM.
- Issue classification is keyword-based.
- Priority detection is rule-based.
- Response generation is template-based.
- Synthetic data is not representative of all real customer reviews.

## 9. Future Enhancements

- Evaluate with a larger, independently labeled dataset.
- Explore transformer-based sentiment models.
- Introduce multilingual review analysis.
- Add LLM-based response drafting with human approval.
- Detect recurring complaints and emerging trends.
- Integrate with external review platforms through secure APIs.

## 10. Conclusion

Revio InsightAI demonstrates an end-to-end review intelligence workflow using machine learning, explainable rules, data visualization, and database persistence.

The prototype is designed to support human decision-making rather than replace human review.
